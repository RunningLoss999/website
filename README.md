# RunningLoss999 — Personal website

A responsive, dependency-free personal site with an interactive accent palette, keyboard-friendly navigation, and reduced-motion support.

## Edit

All content, styling, and JavaScript are in `index.html`. Change project titles, descriptions, and links in the `work` section. Update the introduction and `about` section to make them your own.

## Preview

Open `index.html` in a browser, or run `python -m http.server 8080` from this folder and open `http://localhost:8080`.

## GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, then **main** and **/(root)**. Save. For a repository named `website`, the address is `https://runningloss999.github.io/website/`.

The existing scripts website is linked, not modified. No external libraries, fonts, or tracking are used.
